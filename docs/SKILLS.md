# Skill inventory

Codex Blog includes exactly 33 Skills. `$blog` is the orchestrator and
`$blog-write` is the direct article writer.

| Skill | Purpose |
|---|---|
| `blog` | Route and supervise the complete article-first workflow |
| `blog-write` | Produce the complete SEO Markdown article |
| `blog-strategy` | Define content goals, audience, positioning, and measurement |
| `blog-calendar` | Build a sequenced editorial calendar |
| `blog-brief` | Create an evidence-aware SEO content brief |
| `blog-outline` | Design an intent-complete article structure |
| `blog-rewrite` | Refresh or substantially rewrite existing content |
| `blog-analyze` | Run deterministic content analysis |
| `blog-audit` | Audit a content library or workflow |
| `blog-seo-check` | Review on-page SEO without keyword stuffing |
| `blog-geo` | Improve passage-level AI answer and citation readiness |
| `blog-schema` | Generate evidence-matched structured data |
| `blog-factcheck` | Trace and qualify factual claims |
| `blog-cannibalization` | Find overlapping search-intent pages |
| `blog-decay` | Identify declining content from supplied performance data |
| `blog-sources` | Collect, organize, and synthesize sources |
| `blog-discourse` | Research current public discussion and practitioner signals |
| `blog-brand` | Maintain project brand context |
| `blog-persona` | Define audience and author persona |
| `blog-style` | Learn and apply an inspectable voice profile |
| `blog-brain` | Curate clean-room project/user knowledge |
| `blog-image` | Plan and explicitly generate or attach images after opt-in |
| `blog-chart` | Generate evidence-backed accessible SVG charts after visual opt-in |
| `blog-narration` | Produce narration scripts and explicitly authorized Gemini TTS audio |
| `blog-repurpose` | Adapt completed content to approved downstream formats |
| `blog-taxonomy` | Design categories, tags, and archive structure |
| `blog-cluster` | Plan and execute pillar/cluster content |
| `blog-multilingual` | Plan multilingual content systems |
| `blog-translate` | Translate while preserving meaning and factual support |
| `blog-localize` | Adapt content for a locale rather than translating literally |
| `blog-locale-audit` | Check locale consistency and hreflang-ready relationships |
| `blog-flow` | Apply attributed FLOW Find/Leverage/Optimize/Win prompts |
| `blog-data` | Analyze imports and optional configured search/analytics APIs |

Image planning is listed as a capability, not a default stage. No Skill should
activate `blog-image` solely because an article lacks a visual.
