# Article templates

Templates guide intent coverage; they are not rigid word-count or section-count
quotas. Codex Blog chooses the closest template and adapts it to the supplied
brief, evidence, and audience.

| Template | Best fit |
|---|---|
| `case-study` | Evidence-backed problem, intervention, and outcome |
| `comparison` | Decision support between meaningfully different options |
| `data-research` | Sourced analysis of a supplied or public dataset |
| `faq-knowledge` | A question-led topic where Q&A is the primary intent |
| `how-to-guide` | Goal-oriented procedural guidance |
| `listicle` | A scannable set whose ordering and inclusion criteria matter |
| `news-analysis` | Time-sensitive event plus context and implications |
| `pillar-page` | Broad hub page for a defined topic cluster |
| `product-review` | Transparent evaluation against stated criteria |
| `roundup` | Curated expert, product, or resource collection |
| `thought-leadership` | Defensible original argument with evidence |
| `tutorial` | Detailed learning path with examples and verification |

Specify a template in Codex or with `codex-blog prepare --template NAME`.
When no template is given, the workflow derives one from search intent. FAQ and
Schema are included only when the content genuinely supports them.
